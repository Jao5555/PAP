# Modelos 3D Otimizados — Void Defense

Estes são os modelos que enviaste do meshy.ai, **decimados e prontos para
o browser**. Os ficheiros originais tinham entre 270 mil e 976 mil
triângulos cada (225MB no total) — completamente impraticável para um
jogo com dezenas de inimigos em ecrã ao mesmo tempo. Estes têm entre
2 mil e 32 mil triângulos, guardando a forma e a cor. Total: 2.3MB.

A cor já vem "cozida" nos vértices (não depende de carregar a textura
2048x2048 à parte — mais rápido a carregar no browser).
